# ARCH & GARCH Volatility Forecasting

## Overview

This project was completed as part of an Applied Time Series course at the University of Georgia. The objective was to investigate volatility clustering in financial returns and evaluate the effectiveness of ARCH and GARCH models for modeling and forecasting market risk.

Using daily S&P 500 data from 2018–2025, the analysis explores how volatility changes over time, tests for ARCH effects, compares ARCH(1) and GARCH(1,1) models, and generates volatility forecasts. The project demonstrates practical applications of financial econometrics and time series modeling techniques commonly used in quantitative finance, risk management, and derivatives pricing.

## Results

The analysis finds strong evidence of volatility clustering in S&P 500 returns and shows that GARCH models provide an effective framework for capturing time-varying volatility and forecasting future market risk.
